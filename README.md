# CS Tactical Advantage Training — Homepage Demo

Demo homepage concept for **CS Tactical Advantage Training LLC**, a tactical defense training company in Rindge, New Hampshire.

- Static HTML/CSS/JS, Bootstrap 5.3 grid (via CDN)
- Fonts: Barlow Condensed, Barlow, Share Tech Mono (Google Fonts)
- Icons: Phosphor Icons

## Run locally

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765.

## Placeholder content

This is a demo. Contact details, instructor bio, course details, social links, and photography (Unsplash) are placeholders, marked with `PLACEHOLDER` comments in `index.html`. The inquiry form validates input but is not connected to a backend.
